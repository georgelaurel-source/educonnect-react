# Contributing to EduConnect

1. Obtain repository access from the owner. Each contributor should use their own GitHub account.
2. Clone the repository and create a branch for your task.
3. Make a focused change and run the local server described in README.md.
4. Check the affected page on desktop and mobile sizes. For JavaScript changes, test the relevant search, filtering or reading-list behaviour.
5. Commit with a clear message describing the actual change.
6. Push your branch and open a pull request explaining what changed and what you checked.
7. Ask a teammate to review before merging.

Updating this repository does not automatically publish to the existing live domain. Deployment remains a separate action.

Do not invent contribution histories or testing results. Do not store participant personal data, passwords, tokens or environment secrets in Git.
